# Uber Request Data Analytics

## Project Overview

This project focuses on analyzing Uber ride request data to understand customer booking patterns, trip completion rates, cancellations, and driver availability.

Using SQL, Python (Pandas), and Excel, the project explores ride demand across different hours, weekdays, pickup locations, and request statuses.

The objective is to identify operational challenges and provide insights that can help improve driver allocation and customer experience.

## Tools & Technologies
- **SQL:** Data querying and aggregation.
- **Python (Pandas):** Data cleaning, preprocessing, and exploratory data analysis.
- **Matplotlib & Seaborn:** Data visualization.
- **Microsoft Excel:** Pivot tables and dashboard analysis.

## Key Areas of Analysis
- Overall ride request status and trip completion.
- Hourly and daily booking patterns.
- Pickup location analysis.
- Driver availability and unfulfilled requests.
- Cancellation trends across pickup locations.
- Peak demand identification.

## Key Insights
- Ride requests show noticeable peaks during morning hours (5 AM–10 AM) and evening hours (5 PM–9 PM).
- Weekday demand remains relatively consistent, with Fridays showing a slight increase.
- Airport requests experience significant unfulfilled demand due to driver availability gaps.
- City pickup locations experience a considerable number of cancellations.

## Business Recommendations
- Increase driver availability at airports during peak periods.
- Allocate additional drivers during morning and evening rush hours.
- Investigate the reasons behind city ride cancellations.
- Maintain consistent driver availability throughout weekdays.
- Improve driver allocation based on demand patterns.

## Project Files
- `uber_request_da_project_sql.sql` – SQL queries for request analysis.
- `uber_project_pandas.ipynb` – Python exploratory data analysis.
- `Uber Request Data.xlsx` – Original request dataset.
- `Uber_Dashboard_Analysis.xlsx` – Excel dashboard analysis.
- `uber_data_da_report.pdf` – Detailed findings and recommendations.

## Conclusion

This project demonstrates how ride request data can be transformed into meaningful operational insights. The findings highlight opportunities to improve driver allocation, reduce cancellations, and enhance the overall ride-booking experience.
